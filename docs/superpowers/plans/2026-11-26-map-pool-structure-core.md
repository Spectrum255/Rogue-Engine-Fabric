# 随机地图集核心与结构场景 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 增加数据包驱动的地图集与结构场景，在创建箱庭时确定性抽取固定地图，并支持手动或离开后刷新。

**Architecture:** 新增 `map_scene`/`map_pool` 动态注册表和箱庭内容层。基础维度仍由现有生成器创建，结构场景在维度创建后分批粘贴；选中地图和来源文件缓存到箱庭定义，刷新通过 `RESETTING` 状态与 WAL 恢复。

**Tech Stack:** Minecraft 26.3、Fabric Loader 0.20.1、Fabric API 0.167.0+26.3、Java 25、JUnit 5、Gradle 9.8.2。

---

## 当前范围

本计划实现：

- `map_scene` 与 `map_pool` 数据包注册表。
- 加权确定性抽取、范围筛选和不重复循环。
- `generator_kind=map_pool` 模板。
- 原版结构 `.nbt` 缓存与放置。
- 创建时筛选、实例地图信息查询。
- `RESETTING` 状态、WAL 恢复、手动刷新和离开后刷新。
- 死亡/完成事件记录待刷新请求。
- 内置示例结构、地图集和 profile。
- 单元测试与服务端冒烟。

本计划不实现：

- 模组场景快照格式。
- 完整 Minecraft 存档导入。
- ZIP 地图导入。
- Mod Menu 图形界面与地图预览。

这些内容在核心计划完成后分别制定计划。

## 完成标准
